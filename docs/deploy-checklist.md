# 배포 후 확인 체크리스트

> 대상: https://toridos.cafe24.com
> 소요: 15분 (모바일 항목 포함 시 20분)
> 준비물: 노트북(크롬), 스마트폰

---

## 시작 전에

크롬에서 쇼핑몰을 열고 **개발자도구**를 켭니다.

- Mac: `⌘ + ⌥ + I`
- Windows: `F12`

**Console** 탭을 선택하세요. 아래 확인들은 여기에 명령어를 붙여넣고 Enter를 누르면 됩니다.

> 처음 접속하면 서버가 깨어나느라 **30초쯤 느릴 수 있습니다.** 정상입니다.

---

## 1. SDK가 살아 있나 (1분)

쇼핑몰 아무 페이지나 열고 콘솔에 붙여넣기:

```js
typeof window.__GT
```

| 결과 | 판정 |
|---|---|
| `"object"` | ✅ 정상 |
| `"undefined"` | ❌ SDK가 안 붙음 → 조현에게 알려주세요 |

**그리고 콘솔에 빨간 에러가 있는지 봐주세요.** GhostTracker 관련 에러는 0건이어야 합니다.

- [ ] `window.__GT`가 object
- [ ] 콘솔에 빨간 에러 없음

---

## 2. 한 사람이 한 명으로 세어지나 (3분) ⭐

**가장 중요한 항목입니다.** 예전에는 페이지를 넘길 때마다 다른 손님으로 세어졌습니다.

**순서대로 해주세요:**

1. 홈페이지 접속
2. 콘솔에 붙여넣고 나온 값을 **메모**:
   ```js
   localStorage.getItem('gt_sid')
   ```
3. 상품 하나 클릭해서 들어가기
4. **2분 정도 기다리기** (중요 — 예전 버그는 1분 뒤에 나타났습니다)
5. 장바구니 페이지로 이동
6. 같은 명령어 다시 실행

| 결과 | 판정 |
|---|---|
| 2번과 6번 값이 **같음** | ✅ 정상 |
| 값이 **다름** | ❌ 조현에게 알려주세요 |

- [ ] 세 페이지에서 같은 값 유지

**추가로** — 아래를 실행하면 숫자가 계속 커져야 합니다 (페이지마다 1로 돌아가면 안 됨):

```js
localStorage.getItem('gt_seq')
```

- [ ] `gt_seq`가 페이지를 넘어가며 계속 증가

---

## 3. 어디서 왔는지 기억하나 (3분)

**순서대로:**

1. **주소창에 이 주소를 직접 입력**해서 접속:
   ```
   https://toridos.cafe24.com/?utm_source=instagram&utm_medium=social&utm_campaign=test
   ```
2. 콘솔에서 확인:
   ```js
   JSON.parse(localStorage.getItem('gt_first_touch'))
   ```
3. 상품 페이지로 이동 → **같은 명령어 다시 실행**

| 결과 | 판정 |
|---|---|
| 두 번 모두 `channel: "instagram"` | ✅ 정상 |
| 두 번째에 값이 비거나 바뀜 | ❌ 알려주세요 |

- [ ] 페이지를 넘어가도 `channel`이 `instagram` 유지

## 4. 인스타그램·카카오톡 유입 (3분) ⭐ 폰 필요

**예전에는 이 유입이 전부 "직접 방문"으로 잡혔습니다.** 이번에 고친 부분이라 실제 앱으로 확인이 꼭 필요합니다.

**방법:**

1. 카카오톡에서 **나에게 보내기**로 아래 주소를 보냅니다
   ```
   https://toridos.cafe24.com/
   ```
2. 카톡 안에서 그 링크를 **탭해서 엽니다** (외부 브라우저로 열지 마세요)
3. 아무 상품이나 하나 눌러보고 나옵니다
4. 인스타그램 DM이나 프로필 링크로도 같은 방식으로 한 번 더

- [ ] 카카오톡 인앱으로 접속
- [ ] 인스타그램 인앱으로 접속

> 폰에서는 콘솔을 볼 수 없습니다. **7번(대시보드)에서 결과를 확인**합니다.

## 5. 상품 페이지 동작 (4분) ⭐

상품 상세 페이지에서 **아래를 하나씩** 해주세요. 각 동작 후 콘솔에 에러가 뜨지 않으면 됩니다.

- [ ] 옵션(사이즈) 선택
- [ ] 옵션을 **2~3번 더 바꾸기** ← 예전에 아예 수집이 안 되던 부분
- [ ] 수량 **+ 버튼 2번, − 버튼 1번** 클릭
- [ ] **장바구니** 버튼 클릭
- [ ] 뒤로 가서 목록에서 **Cart 아이콘** 클릭 (상품 위에 뜨는 작은 장바구니)
- [ ] 상품 상세에서 **바로 구매** 클릭

확인용 (선택):

```js
JSON.parse(document.querySelector('meta[property="product:productId"]').content)
```

상품 상세에서 **숫자**가 나오면 정상입니다 (예: `45`).

## 6. 주문 완료까지 (3분)

비회원으로 주문해봅니다. **결제 수단은 무통장 입금**을 선택하세요 (실제 결제 안 됨).

1. 장바구니 → 주문하기
2. 배송지 대충 입력
3. 무통장 입금 선택 → 주문 완료

- [ ] 주문 완료 화면까지 도달

**여기서 막히면 알려주세요.** 비회원 구매가 꺼져 있거나 결제 수단 설정이 필요할 수 있습니다.

## 문제가 있을 때

**"안 돼요"보다 이 세 가지를 주시면 훨씬 빨리 잡습니다.**

1. 어느 페이지에서 (주소 전체)
2. 무엇을 눌렀을 때
3. 콘솔 **Console 탭**과 **Network 탭** 스크린샷

Network 탭에서는 `collect` 로 검색해서 **Status** 열의 숫자를 봐주세요.

| Status | 의미 |
|---|---|
| `201` | ✅ 정상 |
| `502` / `503` | 서버가 깨어나는 중 — 30초 뒤 새로고침 |
| `(failed)` | 주소가 틀렸거나 네트워크 문제 |
| `401` / `403` | 접근 키 문제 |
